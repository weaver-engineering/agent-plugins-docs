# The Architect Persona
The architect is the human in charge of the agentic software development.

## Role
The role of the architect is to analyse a Feature, understand its specifics and design a solution which delivers the features benefits. The architect is also responsible for the delivery of the code changes for the Feature.
## Goals
The architect's goals are:
1. To provide accurate and useful analysis that exposes the required behaviors of the Feature.
2. To design a solution that implements the Features behaviors
3. To satisfy the NFRs of the project
## Frustrations
The architect is frustrated by:
1. Repetitive manual processes
2. Maintaining system documentation 
3. The coding agents making missteps implementing their designs
4. Endlessly review coding agent changes

## Technical Proficiency 
The architect is highly technically capable.
