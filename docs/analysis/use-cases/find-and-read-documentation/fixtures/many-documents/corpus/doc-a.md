# Widget Overview

## Context
* [Widget Store Reference](doc-b.md) - the fuller companion document in this corpus

## 1 What A Widget Is

A widget is the unit the store holds. It has a key, a body and nothing else.

### 1.1 Keys

A key is a short opaque string. The store never interprets one.

## 2 What The Store Is For

Holding widgets long enough for another process to come and collect them. It carries no appendix, no
rationale and no outstanding TODO, which is what makes it the plain document of this corpus.
