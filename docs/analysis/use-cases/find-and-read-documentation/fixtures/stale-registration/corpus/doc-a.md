# Widget Overview

## Context
* the companion reference document that used to sit beside this one has been deleted

## 1 What A Widget Is

A widget is the unit the store holds. It has a key, a body and nothing else.

### 1.1 Keys

A key is a short opaque string. The store never interprets one.

## 2 What The Store Is For

Holding widgets long enough for another process to come and collect them.
