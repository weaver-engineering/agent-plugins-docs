# Registered — before

What the registry holds before anything under `corpus/` is registered: nothing.

| Node | Type | Reference | Lines | Words | Indexed |
|---|---|---|---|---|---|

0 documents, 0 nodes.

An empty registry is a state the registry really takes — it is the state every registry starts in — which is
why it is here. It is the cheapest `before` there is, and it is not the only one a registration could start
from: registering over a registry that already holds documents is the more interesting case, and registering
is absolute rather than differential ([USE-CASE.md](../USE-CASE.md) step 1), so what was there before changes
what the run reports without changing what the registry ends up holding. No example of that is here yet.
